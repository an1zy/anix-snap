# Изменения

## 0.3.3

- Пустой ввод больше не даёт пустую рамку в буфере: ошибка для пустого stdin (`grep ... | asnap -` без совпадений), пустого файла и диапазона из одних пустых строк

## 0.3.2

- `asnap diff ../shared/api.py`: пути с `..` больше не принимаются за диапазон коммитов; диапазон `main..feature` / `main...feature` проверяется по каждой части, ветки со слэшем (`origin/main`) работают
- `asnap diff` вне репозитория: одна понятная строка вместо справки git; ошибки git тоже сокращены до первой строки
- `asnap -` без пайпа больше не зависает, а подсказывает `cat code.py | asnap -`
- Версия в `pyproject.toml` и в коде совпадает, тест следит за этим

## 0.3.1

- Слова действительно в любом порядке: `diff` и `themes` работают в любом месте, `python api.py` и `rust -` тоже
- Ключевые слова главнее файлов: папка `themes/` или файл `neon` больше не ломают команды; файл с таким именем: `./diff`
- В `diff` каждое слово проверяет сам git: ветка/коммит или файл (удалённые файлы тоже); если слово и то и другое, asnap попросит написать `./main`
- `+12,15-17` с запятыми
- Диапазоны проверяются: `0-10` даёт ошибку, `40-10` разворачивается в `10-40`
- Неизвестное слово всегда даёт «не понял», в том числе одиночное (`asnap kaka`)
- stdin без указанного языка: язык угадывается по коду
- `+12` вместе с `--no-lines` или `diff`: предупреждение вместо тихого игнора
- Кеш шрифтов: битый или пустой файл скачивается заново, запись через временный файл
- Буфер обмена: на Linux без PNG честное предупреждение вместо SVG, который никуда не вставляется; на macOS файл кладётся как alias
- Подсказка про PNG на Windows ведёт на resvg, а не на cairosvg

## 0.3.0

- Короткая команда `asnap` (старая `anix-snap` тоже работает)
- Команды словами вместо флагов, в любом порядке: `asnap api.py 10-40 neon +12 png`, `asnap diff staged`, `asnap themes`
- По умолчанию картинка сразу в буфере обмена (`--no-copy`, чтобы выключить); если скопировать не вышло, только предупреждение
- Формат выбирается сам: PNG, если есть cairosvg или resvg, иначе SVG
- Шрифт вшивается в SVG по умолчанию (`--cdn-font`, чтобы оставить ссылку)
- `asnap` без аргументов показывает короткую шпаргалку
- Убраны флаги `-t`, `--hl`, `--diff`, `--rev`, `--staged`, `-l`, `-c`, `--embed-font`, `--list-themes`: теперь это слова

## 0.2.0

- `--copy` / `-c`: картинка сразу в буфер обмена (Windows, macOS, Linux через wl-copy/xclip); если PNG недоступен, копируется SVG-файл
- `--diff`: снимок `git diff` с цветными +/- строками, `--rev` и `--staged`
- `--embed-font`: Fira Code вшивается в SVG, шрифт кешируется после первой загрузки
- PNG через cairosvg или resvg из PATH, `--scale`
- Свои темы: `.json` в папке тем или путь к файлу, `--list-themes`
- Интерфейс RU / EN: по языку системы, `--ui` или `ANIX_LANG`
- Команда `/snap` для ANIX Code (`extras/anixcode/snap.md`)
- Тесты и CI на Windows / macOS / Linux

## 0.1.0

- Первая версия: SVG, диапазон строк `file:10-40`, stdin, темы peach / noir / neon, `--hl`
